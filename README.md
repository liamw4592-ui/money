# 赚钱雷达 (money)

每天自动运行的个人"赚钱线索"机器人：抓 GitHub 热门、AI 赚钱案例、可接的外包活、命理(起名/八字/风水)客户线索，生成中文报告并推送。

## 给其它 AI 工具的速读（最少 token 继续改）
```
+-------------------------------+--------------------------------------------------------+
| 文件                          | 作用                                                   |
+-------------------------------+--------------------------------------------------------+
| scripts/monitor.py            | 唯一主程序。纯标准库。4个抓取函数 + translate + build   |
| .github/workflows/radar.yml   | 每天北京08:00运行；提交 reports/；创建 Issue 触发通知   |
| reports/YYYY-MM-DD.md,latest.md| 每日输出(自动生成，勿手改)                              |
| docs/赚钱路径.md              | 变现路径总表+风险提醒                                  |
| docs/获客渠道.md              | 命理业务获客渠道与产品定价                             |
| docs/沟通话术.md              | 回复客户/雇主的模板                                    |
+-------------------------------+--------------------------------------------------------+
```
扩展方法：
- 新增数据源：在 monitor.py 写一个返回 [{title,desc,url,meta}] 的函数，用 safe(name, fn) 包起来，加进 main() 的 secs 列表。
- 改关键词：HN_QUERIES / LEAD_QUERIES / AI_KW 三个常量。
- 中文翻译：仓库 Secrets 里设置 ANTHROPIC_API_KEY 即自动启用，不设则显示原文标题。
- 表格输出用 CJK 双宽对齐(w/pad/clip)，记事本打开也对齐，改格式请保留。

## 启用步骤
1. 合并本分支到默认分支（定时任务只在默认分支生效）。
2. 仓库 Settings → Actions 允许运行；Actions 页面手动 Run workflow 试跑一次。
3. 在 GitHub 手机 App / 邮箱里开启 Issue 通知，每天会收到一条“赚钱雷达”Issue。
4. （可选）Settings → Secrets 添加 ANTHROPIC_API_KEY。

## 已知限制
- 小红书/抖音/知乎/闲鱼不能合法爬取，只能按 docs/获客渠道.md 手动搜索。
- reddit 偶尔屏蔽 Actions IP，失败会记录在报告末尾“抓取异常”。
- 本地存放位置：个人偏好为 D:\claude code 制作产品集合，请把本仓库 clone 到该目录。
